ZAP! Game Board

Columns: question, answer, action (action is optional: use an action name from the list below, or leave blank for a random one). The board needs 32 questions (16 cards × 2). With fewer, they repeat; with more, extras are ignored. You can also paste CSV here:

Actions (edit to add or change)

A JSON list. Each action has a name, text shown to players, count (copies in the random deck, 0 = only used when named in CSV), and a type:
add (amount, target: self | pick | others | all), zap (target), swap, double, equalize, steal, coin, dice, rps, safety, peek, bonus (amount), none.
Example: {"name":"+3 to all","text":"Everyone gets 3!","type":"add","target":"all","amount":3,"count":2}
