# Seminary Games

Small browser games for seminary class. Each game is a single `index.html` in its own folder, with no build step. Open it in a browser or on the classroom projector to play.

## Games

| Game | Folder | What it is |
|---|---|---|
| One in a Millennium | [`one-in-a-millennium/`](one-in-a-millennium/) | Old Testament team trivia where rarer correct answers score more, with Jeremiah–Joel and Doctrinal Mastery rounds. |

## Adding a game

1. Make a new folder named for the game, such as `my-new-game/`.
2. Put the game's page in that folder as `index.html`.
3. Add a card for it to the menu in the top-level `index.html`, and a row to the table above.
